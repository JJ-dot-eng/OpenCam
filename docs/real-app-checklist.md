# Windows 실제 앱 확인

창 없는 Rust e2e 테스트는 파일 열기·붙이기·저장한 파일의 내용을 확인한다.
아래 항목은 실제 Windows 앱과 탐색기·뷰어·브라우저에서 따로 확인한다.

- [ ] 파일을 창 안으로 끌어오고, 움직이고, 밖으로 빼고, 놓을 때 안내 표시가 맞게 뜨고 사라진다.
- [ ] 빈 편집 창에 놓으면 열리고, 편집 중에 놓으면 맨 뒤에 붙는다.
- [ ] 여러 파일을 놓으면 숫자를 포함한 파일 이름 순서대로 붙는다.
- [ ] 아주 빨리 두 번 놓아도 붙이기가 겹치거나 프레임이 두 번 들어가지 않는다.
- [ ] 대화상자나 편집 도구가 열린 상태에서 파일을 놓아도 화면과 작업이 꼬이지 않는다.
- [ ] 파일 열기·저장 대화상자의 선택, 여러 파일 선택, 취소가 제대로 동작한다.
- [ ] 저장 파일이 이미 있으면 덮어쓰기를 묻고, 취소하면 파일을 그대로 둔다.
- [ ] 붙이는 동안 새 녹화·열기·새로 만들기 버튼의 잠긴 모습과 단축키 동작이 맞다.
- [ ] 붙이기와 저장 진행률, 처리 중 표시가 뜨고 성공·실패 뒤에 사라진다.
- [ ] 성공 알림, 부분 읽기 경고, 건너뛴 파일 안내가 화면에서 읽기 쉽게 보인다.
- [ ] 알림·입력·확인 창에서 Enter·Esc·취소가 맞게 동작한다.
- [ ] 붙이는 중 프로젝트를 바꾸는 요청이 와도 새 작업에 옛 프레임이 붙지 않는다.
- [ ] GIF를 여러 뷰어와 브라우저에서 열어 속도·반복·투명 부분·잔상을 확인한다.
- [ ] WebP를 여러 뷰어와 브라우저에서 열어 속도·반복·투명 부분·화질을 확인한다.
- [ ] APNG를 여러 뷰어와 브라우저에서 열어 속도·반복·투명 부분·화질을 확인한다.
- [ ] MP4·WebM을 여러 동영상 뷰어와 브라우저에서 열어 색·화질·재생 부드러움·끝부분을 확인한다.
- [ ] MP4의 투명 부분이 기본 검정과 설정에서 고른 색으로 각각 저장된다.
- [ ] PNG 연속 이미지의 순서, 저장 결과 폴더 열기, 저장 파일 지우기가 맞다.
- [ ] ffmpeg가 없는 실제 PC에서 동영상 열기·붙이기·저장 안내가 뜨고 앱이 계속 동작한다.
- [ ] 큰 실제 녹화 여러 개를 열고 붙일 때 메모리 한도를 지키며 앞부분과 경고를 보여 준다.
- [ ] 큰 파일을 읽거나 저장하는 동안 화면이 멈추지 않고, 오류 뒤에도 다음 작업을 할 수 있다.
- [ ] 한글·공백이 있는 경로, 쓸 수 없는 폴더, 디스크 여유 부족을 실제 파일 대화상자와 함께 확인한다.
